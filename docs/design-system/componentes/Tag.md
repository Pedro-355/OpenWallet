# Tag

Tags são rótulos curtos, de uma ou duas palavras, que dizem a categoria ou o risco de algo.

- **primary**: categorias informativas ("Perfil", "Nota", "Banco").
- **positive**: algo bom ou seguro ("Economia", "Com CPF", "Mais barato").
- **attention**: prazo ou risco que pede cuidado ("Prazo", "Venceu", "Risco alto", "Sem CPF").
- **neutral**: o resto ("Data prevista", "Cancelada").
- Não use tag como botão: ela não é clicável.

```tsx
<Tag tone="attention">Venceu</Tag>
```
